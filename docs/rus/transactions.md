# Соединения и транзакции

[Главная](index.md) · [English](../eng/transactions.md)

## Открытие соединения

```python
from litecrate import Database

db = Database("players.sqlite3")
```

Конструктор `Database(db_path, timeout=30.0)` принимает строку или `pathlib.Path`. Если файла нет, SQLite создаёт его. `":memory:"` создаёт базу в оперативной памяти, существующую до закрытия соединения.

Параметр `timeout` задаёт время ожидания освобождения блокировки базы в секундах; значение по умолчанию - `30.0`.

## Транзакции

Блок `with db:` объединяет несколько операций в одну транзакцию:

```python
with db:
    db.insert("players", login="ada")
    db.insert("players", login="guest")
```

При входе выполняется `BEGIN`. Если блок завершился успешно, вызывается `COMMIT`. Если из блока выходит исключение, выполняется `ROLLBACK`; изменения схемы и внутреннего кеша метаданных также откатываются.

### Пример отката

```python
import sqlite3

try:
    with db:
        db.insert("players", login="ada")
        db.insert("players", login="ada")

except sqlite3.IntegrityError:
    print("Transaction rolled back")
```

В примере предполагается, что таблица `players` уже создана, а `login` объявлен как `UNIQUE`. Вторая вставка вызывает исключение, и первая вставка из этого блока тоже откатывается.

Вне `with db:` соединение работает в режиме автоматической фиксации SQL-команд. После завершения одной транзакции можно начать следующую.

**Ограничения:** вложенные `with db:` на одном экземпляре не поддерживаются и вызывают `RuntimeError`. Контекстный менеджер управляет транзакцией, но **не закрывает** соединение. Ошибки при фиксации транзакции (`COMMIT`) передаются вызывающему коду.

## Закрытие соединения

```python
db.close()
```

Если соединение должно закрыться даже при исключении, используй `try/finally`:

```python
db = Database("players.sqlite3")
try:
    print(db.get_tables())
    
finally:
    db.close()
```

Для этого также подходит `contextlib.closing()`.

**Многопоточность:** экземпляр `Database` не обеспечивает собственную синхронизацию. Если к нему обращаются из разных потоков, доступ нужно защищать внешней блокировкой на протяжении всей транзакции.

Настройки журналирования и очистки вынесены отдельно: [Настройки и обслуживание](settings.md).
