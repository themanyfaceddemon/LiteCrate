# Работа с записями

[Главная](index.md) · [English](../eng/records.md)

## Добавление

`insert(table_name, **values)` добавляет запись. Поля передаются именованными аргументами.

```python
player_id = db.insert("players", login="ada", level=3)
```

Метод возвращает `lastrowid` - идентификатор последней вставленной строки (`int` или `None`). Если не передать поля, выполняется вставка со значениями по умолчанию.

## Чтение

| Метод | Результат |
|---|---|
| `select(table_name, query="", *args)` | Список словарей; если совпадений нет - `[]`. |
| `select_one(table_name, query="", *args)` | Одна подходящая запись в виде словаря или `None`. |
| `count(table_name, query="", *args)` | Количество подходящих записей (`int`). |

```python
players = db.select("players")
player = db.select_one("players", "login = ?", "ada")
total = db.count("players", "level >= ?", 5)
```

Без условия методы чтения обращаются ко всем строкам таблицы. Если требуется конкретная запись, укажи условие по первичному ключу или уникальному полю: без явного порядка SQL не гарантирует, какая из нескольких подходящих строк будет выбрана первой.

### Условия поиска

В `query` передаётся SQL-выражение **без** слова `WHERE`, а значения для `?` - следующими позиционными аргументами.

```python
db.select("players", "level BETWEEN ? AND ?", 3, 10)
db.select_one("players", "login = ? AND level >= ?", "ada", 5)
```

Не вставляй пользовательские значения непосредственно в SQL-строку: передавай их параметрами `?`. Сам текст SQL-условия должен задаваться доверенным кодом.

В [гибких таблицах](flexible.md) имена дополнительных полей верхнего уровня автоматически преобразуются в обращения к JSON.

## Обновление

`update(table_name, query, *args, **values)` изменяет указанные поля у подходящих записей.

```python
changed = db.update("players", "login = ?", "ada", level=10)
```

Метод возвращает количество затронутых строк. Если совпадений нет - `0`. Необходимо передать хотя бы одно новое значение и непустое условие.

## Удаление

`delete(table_name, query, *args)` удаляет подходящие строки и возвращает их количество.

```python
removed = db.delete("players", "login = ?", "ada")
```

Непустое условие обязательно.

## Обновление и удаление всех записей

Чтобы изменить или удалить все строки таблицы, используй `update_all(table_name, **values)` или `delete_all(table_name)`. Оба метода возвращают количество затронутых строк. Для `update_all()` нужно передать хотя бы одно новое значение.

```python
changed = db.update_all("players", level=0)
removed = db.delete_all("players")
```

## Ошибки и ограничения

В обычной таблице запись в неизвестную колонку вызывает `KeyError`. В таблице с `flexible=True` дополнительные поля записываются в JSON - см. [Гибкие поля](flexible.md).

Ограничения SQLite (`UNIQUE`, `NOT NULL`, `PRIMARY KEY` и другие) продолжают действовать. Например, нарушение уникальности вызывает `sqlite3.IntegrityError`.

Если несколько записей должны измениться как единое целое, используй [транзакцию](transactions.md).
