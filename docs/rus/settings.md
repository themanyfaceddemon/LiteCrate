# Настройки и обслуживание

[Главная](index.md) · [English](../eng/settings.md)

LiteCrate предоставляет методы для настройки SQLite и обслуживания базы данных.

## Журналирование

Метод `set_journal_mode(value)` устанавливает режим журналирования SQLite.

```python
db.set_journal_mode("WAL")
```

Поддерживаемые значения: `DELETE`, `TRUNCATE`, `PERSIST`, `MEMORY`, `WAL`, `OFF`.

Если SQLite не удалось установить выбранный режим, метод вызывает `RuntimeError`.

## Автоматическое освобождение места

Метод `set_auto_vacuum(value)` управляет освобождением неиспользуемых страниц базы данных.

| Значение | Поведение |
|---|---|
| `NONE` | Автоматическое освобождение отключено. |
| `FULL` | Освобождает неиспользуемые страницы при фиксации транзакций. |
| `INCREMENTAL` | Позволяет освобождать страницы вручную, без автоматической очистки. |

```python
db.set_auto_vacuum("INCREMENTAL")
```

При переключении существующей базы между `NONE` и другими режимами необходимо выполнить `vacuum()`, чтобы изменение вступило в силу. Переключение между `FULL` и `INCREMENTAL` этого не требует.

## Обслуживание базы данных

### VACUUM

Метод `vacuum()` перестраивает базу данных, освобождая неиспользуемое пространство.

```python
db.vacuum()
```

Метод нельзя вызывать внутри активной транзакции.

### INCREMENTAL VACUUM

Метод `incremental_vacuum(pages=None)` позволяет освобождать неиспользуемые страницы без полной перестройки базы данных.

```python
db.incremental_vacuum(100)
```

В этом примере SQLite попытается освободить до 100 страниц.

Если параметр `pages` не указан, освобождаются все доступные свободные страницы:

```python
db.incremental_vacuum()
```

Параметр `pages` принимает положительное целое число или `None`. Некорректное значение вызывает `ValueError`.

Метод работает только при установленном режиме `INCREMENTAL`. В остальных режимах вызов не оказывает эффекта.
