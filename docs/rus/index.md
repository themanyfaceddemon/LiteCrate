# LiteCrate

[Выбор языка](../index.md) · [English](../eng/index.md)

LiteCrate - небольшая библиотека для работы с SQLite на Python. Она позволяет создавать таблицы, добавлять и изменять записи через именованные аргументы, а для поиска использовать SQL-условия.

Если у записей различается набор полей, дополнительные значения можно хранить в JSON без изменения схемы таблицы.

Библиотека использует стандартную библиотеку Python и требует Python 3.13 или новее.
